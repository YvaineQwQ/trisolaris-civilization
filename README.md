## 0. 一键启动（推荐）

**以后请不要收藏/依赖旧的 5173/4173 地址**：它们是临时开发服务器，电脑重启或关闭窗口后就失效，这是“游戏打不开”的唯一常见原因。

- 双击桌面快捷方式 **「三体纪元」**（已创建），或项目根目录的 **`启动游戏.cmd`**
- 脚本会用稳定的本地静态服务器打开游戏：`http://127.0.0.1:8080/`
- 窗口保持打开即可；关闭窗口=停止服务。端口被占用会自动改用 8081/8082
- 如浏览器没有自动打开，手动访问 <http://127.0.0.1:8080/>

分享给朋友：见 `分享给朋友.md` / `docs/SHARING.md`；在线托管最省事。

## 1. 快速开始

环境要求：Node.js ≥ 20（开发环境实测 Node v26），npm。

```bash
cd three-body-civilization
npm install

# 开发模式（Vite，自动重载）
npm run dev
# 浏览器打开 http://127.0.0.1:5173

# 生产构建 + 本地预览
npm run build
npm run preview     # http://127.0.0.1:4173

# 单元 / 集成测试（纯逻辑，无需浏览器）
npm test            # 13 个测试文件 / 120 个用例

# 浏览器端 E2E 验收（headless Edge/Chrome + CDP；需先运行 npm run dev）
npm run dev        # 终端 A
npm run test:e2e   # 终端 B，约 17 分钟，55 项浏览器验收
```

游戏为纯前端单机应用，不需要后端；存档保存在浏览器 IndexedDB 中，可导出/导入 JSON 文件。

## 2. 核心特色

| 系统 | 实现要点 |
| --- | --- |
| 时代进化 | 文明从 E1 原始部落（无金属、无电力，只有食物/水/矿物/知识）一步步发展到 E5 星际文明：38 座建筑按五时代分层，主升级链（住房/食物/水/工业/科研）需逐级升级、旧时代建筑产出衰减；26 项科技按时代解锁；时代推进由人口、科技分布与观测等级等明确条件自动触发 |
| 三维三体物理 | 三颗恒星完整相互 N-body；X/Y/Z 真实三维坐标与轨道倾角；固定步长 leapfrog（KDK，1/1600 年）；软化势 + 自适应子步保证近距离交会稳定；实时监测能量、动量、角动量与数值溢出 |
| 随机三维星系 | 种子确定性生成层级三体 + 母星；**用真实积分器做预模拟筛选**：行星必须存活、不被抛射、辐照与温度落在可生存区间；星系分类（稳定/混沌/极端/特殊）由预演指标决定 |
| 双层数据系统 | `PhysicsState`（真实状态）与 `ObservationState`（玩家知识）严格分离；UI 与 3D 视图只读观测数据，无法泄露未观测信息 |
| 科学观测 | 6 级天文台能力阶梯；8 种观测任务；每次任务含随机噪声与系统偏差；加权最小二乘/测量融合估计位置、速度、质量；5σ 残差会触发"预测模型失效"发现 |
| 不确定预测 | 基于玩家模型的三维蒙特卡洛集成预测；不确定性随时间增长；低等级预报窗口极短，最高等级也无法无限期准确 |
| 文明经营 | 6 种资源（金属 E2 解锁、能源 E3 解锁）、人口/住房/就业/稳定度六因子、38 座跨时代建筑（含升级链）、26 项五方向科技、殖民地、行星发动机 |
| 界面视觉 | Endfield/Arknights 风格几何科幻界面：时代时间线与条件清单、同心圆仪表、平行四边形页签、切角面板、排线/刻度/扫描线、按时代分组的建造与科技树 |
| 灾害与预警 | 全部由真实恒星几何、辐照、温度与轨道变化驱动；低等级天文台看不到接近事件；预警来自玩家自己的预测模型 |
| 2.5D 双视图 | 2D 主视图 = X-Z 俯视投影（Y 以高度数值/辉光/指引线提示）；3D 辅助视图 = Three.js 全息空间（轨道平面、不确定性球、三维距离）；两者共享同一物理状态与观测数据，切换不重置模拟 |
| 存档 | IndexedDB 自动/手动存档，完整保存真实天体状态、观测历史、估计、发现、事件；支持导出/导入 JSON |

## 3. 操作说明

- **鼠标**：在星系视图中滚轮缩放、左键拖动平移、单击选中天体、双击聚焦；3D 视图中左键拖动旋转、滚轮缩放、右键/中键平移。
- **键盘**：
  - `空格` 暂停 / 继续
  - `Esc` 关闭弹窗 / 打开暂停面板
  - `1`–`6` 切换右侧页签（恒星 / 环境 / 观测 / 预测 / 科技 / 灾害）
  - `F` 聚焦当前选中天体
  - `T` 显示/隐藏已观测轨迹，`P` 显示/隐藏预测轨迹
  - 底部 dock：建造、科研、天文台、星系地图、事件日志、存档、设置、帮助；顶部：暂停、0.5×–32× 时间加速、单步结束回合、存档、设置
- **视图切换**：中央右上角 `2D / 3D`，切换不影响模拟时间、选中对象与观测数据。

## 4. 时代进化（v1.2 新增）

文明开局是一个只有 500 人的原始部落：聚落营地 ×1、原始农田 ×2、水井 ×1、采石场 ×1；没有金属、没有电力，观测只能靠肉眼（观测 Lv.0）。

| 时代 | 名称 / 副标题 | 解锁重点 |
| --- | --- | --- |
| E1 | 仰望星空 / 原始部落 | 食物、水、矿物、知识；原始农田、营地、水井、采石场、长者议事棚、观星台 |
| E2 | 文明曙光 / 农业城邦 | 金属冶炼；灌溉农田、城邦住宅、水渠、矿场、学园、集市 |
| E3 | 混沌时代 / 蒸汽与电气 | 电力；机械化农场、水处理厂、燃煤电站、钢铁厂、机械厂、科学院、地下避难所 |
| E4 | 预测未来 / 信息与航天 | 高级住区、垂直农场、循环水厂、核电站、自动化矿山、超算中心、气候调节、卫星站 |
| E5 | 文明的选择 / 星际文明 | 生态穹顶、人造生物圈、聚变反应堆、纳米工厂、量子实验室、太空港、殖民基地、行星发动机、深空雷达 |

- 时代推进条件在左侧「时代进程」面板实时显示（人口、累计科技、该时代科技、观测等级），满足后自动进入下一时代并写入事件日志。
- 旧时代建筑需要点击「升级」进入下一层级（例如 聚落营地 → 城邦住宅 → 住宅区 → 高层住区 → 生态穹顶城市）；未升级的旧建筑在新时代表现为「旧时代 · 产出衰减」（1 代 ×0.8，2 代以上 ×0.6）。
- 科技按时代解锁（E1 只能研究 E1 科技），天文台 Lv.2 起需要对应天文学科技与时代；Lv.1 通过建造「观星台」获得。

## 4.1 游戏目标与模式

- **胜利**：时代 E5 后建立 4 级自给殖民地 / 建成并启动行星发动机 / 母星死亡但殖民地存续（火种计划）；生存模式中存续 160 年。
- **失败**：人口归零、长期饥荒、稳定度归零、母星不可居且无殖民地、母星被摧毁/抛离。
- **模式**：剧情（叙事节奏）、标准（完整循环）、生存（存续挑战）、沙盒（不判负，自由测试）。

文明通过「建设 → 观测 → 研究 → 预测 → 应对」循环推进时代：E1 仰望星空 → E2 文明曙光 → E3 混沌时代 → E4 预测未来 → E5 文明的选择。

```

  src/

    environment/              # 三星辐照、温室、热惯性气候、天气
    generation/               # 三维随机星系生成 + 物理预筛 + 分类
    observation/              # 测量模型、估计、玩家模型、蒙特卡洛预测、科学发现
    civilization/             # 资源、人口、稳定度六因子
    economy/                  # 回合结算：生产/消耗/人口/时代/殖民地/胜负
    buildings/                # 25 座建筑定义与施工管线
    technology/               # 26 项五方向科技树与效果聚合
    events/                   # 物理灾害、灾害预警、文明危机
    game/                     # Game 主循环、GameState、ViewModel、RenderScene(2D/3D)
    render/                   # Canvas 2D 主视图（X-Z 投影 + 高度提示）
    render3d/                 # Three.js 三维辅助视图
    ui/                       # DOM 界面（HUD/面板/dock/模态/菜单）
    save/                     # 序列化 + IndexedDB 存储 + 导入导出
  tests/                      # physics/generation/environment/observation/systems/game/e2e
  docs/                       # 架构、物理模型、游戏设计、API、测试报告、美术规范
  public/                     # 程序化生成的美术资产（背景/插图/图标）
  scripts/                    # 无头浏览器 CDP QA 驱动
```

## 6. 科学模型与简化声明

- 单位：AU / 太阳质量 / 年，G = 4π²。
- 三颗恒星：完整相互 N-body；母星：**测试粒子**（受三颗恒星引力，不回推恒星），因 M_planet/M_star < 1e-5，该简化误差可忽略，但仍属模型近似。
- 软化长度 0.008 AU：把未解析的近距交会/潜在恒星并合替换为平滑势；近距离交会时按预测位移自适应细分步长（同一固定时钟预算内），并在诊断中记录。
- 行星质量为地球质量单位，仅在守恒量核算时换算为太阳质量。
- 气候：辐照平衡温度 + 温室 + 热惯性时间常数，温度不随恒星距离瞬时跳变；大气流失/水相态/生态为简化模型。
- 观测：测量噪声 + 每次任务系统偏差；估计为测量融合 + 短弧加权最小二乘；质量估计为带弱先验的融合（游戏化简化），不读取真实质量。
- 预测：仅从玩家模型出发的三维集合推演，不确定性随时间增长；不保证可预测性上界。
- 随机性只在星系生成阶段注入（种子确定性）；模拟过程中不修改恒星质量或轨道；特殊事件只由物理状态触发。

详见 `docs/PHYSICS_MODEL.md`、`docs/ARCH_3D.md`、`docs/OBSERVATION_API.md`、`docs/GAME_DESIGN.md`。
