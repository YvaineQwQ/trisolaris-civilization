# UI 视觉重构（Endfield / Arknights 方向）

> 目标：把初版的“深色面板 + 数字”升级为硬科幻工业终端式的信息界面；保留全部功能与冻结契约（src/game/viewTypes.ts）。

## 设计语言

- 基底：近黑石墨（#070a0e / #0b1118），冷青主强调（#37e5ff），钢白正文，琥珀警示，红色危险，紫色辅助。
- 几何母题：同心圆/圆弧（时代进度、观测瞄准、等级刻度）、平行四边形/梯形（页签、按钮、资源胶囊、dock 底板）、切角矩形（面板/模态四角切斜）、角标与刻度、45° 排线、扫描线与噪点。
- 信息层级：英文小标签（全大写、宽字距）作装饰语义层；中文为主信息；数字统一等宽。
- 动效：切角高亮、环形描边进度、数值滚动、入场扫描线；尊重 prefers-reduced-motion。

## 本次重构落地的界面

1. 顶部 HUD：斜切收口的时间/星历/回合、E1–E5 时代徽记、人口与稳定度环形仪表、资源条限制为已解锁资源（未解锁显示「E3 解锁」提示）、灾害雷达按钮、平行四边形时间控制组。
2. 左侧「文明控制台」：E1–E5 时代时间线（已过/当前/未来）、当前时代解锁摘要、**下一时代条件清单**（人口/科技总数/同代科技/观测等级，实时勾选与进度）；人口环形仪表与稳定度六因子。
3. 右侧「观测与决策」：平行四边形页签；恒星/环境/观测/预测/科技/灾害全部换装；科技树按**时代列**组织（E1–E5），未到时代显示锁定遮罩与「E2 文明曙光 解锁」提示；观测任务显示时代货币（E1–E2 食物、E3+ 能源）。
4. 建造终端：建筑按时代分组（E1–E5，共 38 座）；卡片显示时代徽记、tier 刻度、成本/工期/维护/效果；旧时代建筑显示「旧时代·产出衰减」与**升级为下一级**按钮（显示升级成本/工期/时代门槛，未满足时禁用并说明原因）；施工队列区分「新建 / 升级」。
5. 天文台面板：Lv0–Lv6 同心圆等级阶梯；Lv0 时提示先建造观星台（不显示无效升级）；高级等级显示时代门槛与前置科技。
6. 中央观测场：折角图例、切角状态条、斜切 2D/3D 切换、六边形缩放按钮、选中瞄准环与数据卡；3D 视图切换不重置模拟、选中与时间。
7. 菜单 / 新游戏 / 暂停 / 结局 / 存档 / 日志 / 地图 / 设置 / 帮助：统一切角框体与几何装饰；新游戏页面加入「文明从原始时代起步」说明与 E1→E5 路线条；帮助页更新新手指引与时代说明。
8. 响应式：1280×720 与 1600×900 均无溢出，滚动限制在面板内部。

## 技术要点

- 纯 CSS/SVG 实现几何装饰（clip-path、conic/radial-gradient、mask、伪元素），不新增运行时依赖。
- 面板更新维持 10Hz 轮询；不再每帧重建 DOM；动画使用 transform/opacity。
- 所有按钮连接真实 GameActions（含新增 upgradeBuilding）；未就绪字段做 undefined 安全降级。
- 视觉资源：public/ui/*.svg（HUD 环、切角角标、排线、斜切分隔、平行四边形、雷达），public/backgrounds/*-v2，public/images/era-1..5-v2。
