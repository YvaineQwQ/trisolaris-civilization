# UI 视觉重构规格（Endfield / Arknights 方向，阶段 13）

> 必须在现有功能与冻结契约（`src/game/viewTypes.ts`）内重构；不得删除任何可用按钮/功能，所有新控件都要接到真实 action。

## 1. 设计语言（硬科幻 · 工业终端 · 高密度信息）

- 参考气质：明日方舟 / 终末地 / 硬核航天控制台。避免“普通网页卡片”感。
- 色彩：近黑石墨底（#070a0e / #0b1118），冷青主色 #37e5ff，钢白文本 #e8f2f7，琥珀警示 #ffc857，危险 #ff5d6c，辅助紫 #b48cff。面板用低透明度玻璃 + 细描边 + 内发光。
- 几何：**同心圆/圆弧**（时代进度环、资源环形表、观测瞄准环）、**平行四边形/梯形**（页签、按钮、dock 图标底板、标签）、**切角矩形**（clip-path 面板四角切斜）、细网格、对角线排线（hatching）、角标与刻度、扫描线/噪点。
- 字体：标题用紧凑无衬线（可用系统字体 + letter-spacing），数据用等宽（tabular-nums），中文正文清晰。英文小标签（全大写、字距宽）作装饰语义层。
- 动效：入场扫描、数值滚动、环形进度描边、hover 时的切角高亮；尊重 `prefers-reduced-motion`。
- 不使用侵权素材；装饰优先 CSS/SVG 几何，其次本地程序化资产（public/ui/**）。

## 2. 需要重做/新增的界面

1. **顶部 HUD**：左右两端斜切收口；时间/星历/回合、时代徽记（同心环 + E1..E5）、人口环、资源条改为带刻度/斜切胶囊；灾害警报为旋转雷达环；时间控制为平行四边形按钮组。
2. **左侧面板**：时代时间线（5 节点同心弧/竖轨，已过/当前/未来三态）+ 当前时代解锁摘要 + 下一时代条件清单（勾/进度）；人口/稳定度用环形仪表；资源列表隐藏未解锁资源（view.resources[].locked），解锁时显示“E3 解锁”提示。
3. **右侧面板**：页签改为梯形/平行四边形；恒星卡、环境、观测、预测、科技、灾害全部换装；科技树按**时代列**组织（E1..E5 横向/纵向均可），未到时代显示锁；观测任务显示货币（食物/能源，view.observation.taskOptions[].costLabel）。
4. **中央视图叠加**：观测边框角标、图例改为折角面板、2D/3D 切换为斜切开关、缩放按钮六边形；选中天体信息用同心圆瞄准环 + 切角数据卡。
5. **底部 dock**：8 个入口用平行四边形/六边形图标底板 + 斜切文字；时间控制可保留在顶部。
6. **建造面板**：建筑按时代分组；卡片显示时代徽记、tier 刻度、成本/维护、效果；已建旧时代建筑显示“旧时代 · 产出衰减”与**升级按钮**（调用 `actions.upgradeBuilding(id)`，显示升级成本/工期/不可用原因）。施工队列区分“新建/升级”。
7. **科研面板**：时代列 + 锁定遮罩；当前研究环形进度与剩余回合。
8. **天文台面板**：等级阶梯用同心圆刻度；下一级显示时代要求（view.observatory.next.requiresEra/eraOk）。
9. **菜单/新游戏/结局**：保留现有信息结构，换装几何框体；新游戏预览页加入“文明从原始时代起步”的说明与时代路线条。
10. **暂停/设置/帮助/存档/日志/地图**：统一换装；帮助页补充新手指引（原始时代→观星台→农业→城邦→工业→航天）。
11. **1280×720 / 1600×900** 均不得溢出；滚动只发生在面板内部。

## 3. 工程约束

- 只改 `src/ui/**`（styles.css 可整体重写）；必须 `npx tsc --noEmit` 0 错误。
- 所有按钮必须调用真实 action；后端暂缺的字段先做安全降级（如 `view.buildings.available[].upgradeToId` 为空时隐藏升级按钮）。
- 性能：面板更新仍按 10Hz 轮询；避免每帧重建；CSS 动画尽量用 transform/opacity；装饰层 pointer-events:none。
- 用 `node scripts/qa-run.mjs` 或自建 CDP 脚本在真实浏览器截图自检（dev server 由 lead 提供；必要时自行后台启动，但不要占用 5173）。
- 交付：`docs/UI_REDESIGN.md`（设计语言/组件/截图路径/已知缺口）+ 截图（菜单、新游戏、游戏 2D、3D、建造升级、科技、时代时间线、1280×720）。
