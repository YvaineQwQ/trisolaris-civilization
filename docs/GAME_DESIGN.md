# 游戏设计说明

## 1. 核心循环

```
建设文明 → 建设/升级天文台 → 执行观测 → 研究科技 → 建立动力学模型
        → 预测风险 → 储备/建造防护 → 度过灾变 → 进入新时代
```

时间以固定物理步长连续推进，文明经济按「回合」（0.5 模拟年）结算；玩家可随时暂停、0.5×–32× 加速或单步结束回合。

## 2. 观测即真相

- 玩家开局只有基础观测站（Lv.1）与肉眼校准数据：恒星方位、颜色、亮度，精度约 ±0.3–0.6 AU，没有速度与质量。
- 六个观测等级逐级解锁：距离（Lv2）、速度与质量初估（Lv3）、三体建模/轨道要素（Lv4）、环境趋势与灾害概率（Lv5）、多模型交叉验证与混沌敏感性（Lv6）。
- 观测任务共 8 种：单星定位、恒星测距、速度测量、母星观测、双星相对观测、三星联合观测、长期连续观测、异常轨道分析。不同任务有不同的能源消耗、回合数、精度倍率与数据收益。
- 每次任务有随机测量噪声 + 固定系统偏差；多次观测可压低误差，但系统偏差不会在单次任务内平均掉。
- 低等级看不到高级数据：UI 星级面板与 3D 视图都只消费 `ObservationState`。
- 玩家模型的三体推演与真实物理分离：新观测与旧模型残差 >5σ 时触发「预测模型失效」发现，模型作废，必须重新观测建模。

## 3. 预测与不确定性

- 3 级及以上可建立玩家模型（三星位置+速度）。
- 预测为三维蒙特卡洛集成（6+2·等级个成员，按 1σ 扰动初值），输出时间切片均值、集合离散度、可靠年限、最近接近。
- 预测不确定性随时间增长；低等级可靠期只有数年，最高等级也在混沌敏感性下迅速发散。UI 用虚线 + 半透明不确定带表达，3D 视图用半透明球体表达。

## 3.5 时代进化系统（v1.2）

文明从原始部落走向星际文明，共五个时代：E1 仰望星空（原始）→ E2 文明曙光（农业城邦）→ E3 混沌时代（蒸汽与电气）→ E4 预测未来（信息与航天）→ E5 文明的选择（星际）。每个时代解锁不同资源（金属 E2、能源/电力 E3）、38 座建筑按时代分层并可逐级升级、26 项科技按时代开放；时代推进由左侧面板列出的条件（人口、累计科技、该时代科技、观测等级）自动触发，旧时代建筑在新时代产出衰减直至升级。开局为 E1：500 人、聚落营地/原始农田/水井/采石场，无金属无电力，观测等级 0（需建造观星台获得 Lv.1），观测任务以食物支付；E3 起才出现电网与能源货币。
## 4. 文明经济

- 资源：食物、水、能源、矿物、金属、科研点；各有库存上限与维护消耗。
- 人口：食物/水/住房/温度/健康/秩序六因子影响稳定度；稳定度影响生产与人口增长；缺粮会积累饥荒压力直至文明崩溃。
- 建筑 25 座：基础（居住/农业/水厂/发电/仓库/学校/医疗）、工业（矿场/冶炼/工业园/机械厂）、科研（天文台/科学院/超算/轨道研究所）、高级（避难所/气候调节/太空港/殖民基地/轨道太阳能/聚变堆/深空雷达/生态穹顶/量子实验室/行星发动机）。
- 科技 26 项、五方向（天文学/能源学/工业学/生物学/航天学），逐级解锁建筑与观测能力；天文台 2–6 级升级需要对应天文学科技与资源。
- 时代：由「天文台等级 / 已研究科技数」决定进度，共五个时代。

## 5. 灾害与危机

- 物理灾害全部来自真实状态：恒星近距离接近（最近距离）、辐射风暴（辐照峰值）、极端高温/严寒（温度极值）、轨道扰动（轨道半径变化）。
- 灾害影响：农业/能源需求/稳定度/直接人口损失；建筑（避难所、气候调节）与科技提供抗性减免，难度倍率放大/缩小灾难。
- 预警只来自玩家自己的预测模型：低等级天文台可能直到灾害发生才"感觉"到它；高级预测可提前数年发现接近事件。
- 文明危机：饥荒、水荒、能源危机、社会动荡、生态崩溃、行星寒冬，由实际资源流与环境状态触发。

## 6. 胜负与结局

- 胜利：E5 + 4 级自给殖民地（星际文明）/ E5 + 行星发动机（流浪行星）/ 母星死亡但殖民地 ≥3 级（火种计划）；生存模式存续 160 年。
- 失败：人口归零、长期饥荒、稳定度归零、母星不可居且无殖民地、母星被毁/抛射。
- 结局界面展示种子、存续时间、时代、人口、观测等级、科技与殖民地状态。

## 7. 界面（v1.2 视觉重构）

16:9 硬科幻工业终端风格：几何装饰（同心圆/圆弧/平行四边形/切角/排线）、E1–E5 时代时间线与条件清单、锁定资源隐藏、按时代分组的建造面板（含旧时代建筑升级按钮与成本）、按时代列组织的科技树、观测货币显示、2D/3D 切换。详见 docs/UI_REDESIGN.md。


16:9 布局：顶部 HUD（时间/时代/人口/资源/警报/时间控制）、左侧文明面板（概览/人口资源/建筑/社会状态）、中央星系视图（2D/3D 切换）、右侧决策面板（恒星/环境/观测/预测/科技/灾害）、底部 dock（建造/科研/天文台/星系地图/日志/存档/设置/帮助）。关键操作均有真实功能，暂停/加速/保存/读档/视图切换不重置模拟。

## 8. 美术风格

硬科幻、深空观测、未来主义、航天控制中心：深空蓝黑底、青色主强调、琥珀警告、红色危险、细线网格、等宽数字、毛玻璃面板、扫描线/噪点质感、程序化星空与辉光。详见 `docs/ART.md`。
