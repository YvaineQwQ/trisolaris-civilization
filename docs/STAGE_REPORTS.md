# 分阶段开发报告（0–11）

> 每个阶段都以真实文件与真实测试结果交付；`npx vitest run` 当前 13 文件 / 120 用例全绿，`npm run build` 成功。

## 阶段 0 · 开发环境与项目架构 ✅

- 环境：Windows 11 / Node v26.13.1 / npm 11.20.0；Vite 6 + TypeScript 5（strict）+ Vitest。
- 结构：`src/{core,physics,environment,generation,observation,civilization,economy,buildings,technology,events,game,render,render3d,ui,save}`，`tests/`、`docs/`、`public/`、`scripts/`。
- 统一数据接口 `src/game/viewTypes.ts`（ViewModel / RenderScene / RenderScene3D / GameApi / AppController），UI 与渲染器不 import 模拟内部。
- 交付：可启动的 Vite 应用、日志系统、确定性 RNG、错误条与降级机制。

## 阶段 1 · 三维三体物理引擎 ✅

- 三维牛顿引力 + 速度 Verlet/leapfrog 固定步长；软化势 + 自适应子步；守恒量诊断（能量/动量/角动量/溢出）。
- 行星为测试粒子（界面明示）；轨迹历史、距离/速度/加速度、暂停/单步/加速/重置、碰撞（软化）事件。
- 测试：动量守恒 <1e-9；120 年能量漂移 <1%；300 年无 NaN；改变质量轨迹改变；3D 倾角真实；近距交会不产生无穷。

## 阶段 2 · 随机三维星系生成 ✅

- 种子确定性生成层级三体 + 母星，随机质量/位置/速度/倾角/平面；同种子可复现，不同种子不同。
- 物理预筛（存活、束缚、辐照带、温度带、舒适占比、轨道稳定性）+ 细步复核；基于预演指标的四类分类。
- 新游戏界面：种子输入/随机、难度、模式、实时预览（分类、混沌指数、抛射风险、交会次数、警告、3D 轨迹）、开始游戏。
- 测试：7 项生成测试全绿；同种子指纹一致；3D 非共面；筛选系统经真实积分器 50 年存活。

## 阶段 3 · 行星与环境 ✅

- 三星辐照（3D 距离）、温室、反照率、热惯性时间常数（温度不会瞬时跳变）、水相态可用性、大气侵蚀、生态、天气。
- 气候随真实恒星几何演化；与文明农业/能源需求/稳定度联动。
- 测试：辐照平方反比、3D 高度影响辐照、热惯性、极端温度降低宜居度、长期有限。

## 阶段 4 · 天文台与科学观测 ✅

- 测试：4 文件 21 用例（数据隔离、等级误差下降、预测不确定度增长、残差触发失效）。

## 阶段 12 · 时代进化系统（v1.2）✅

- 五时代（原始→星际）内容重构：38 座建筑、26 项科技、资源解锁（金属 E2 / 能源 E3）、五条主升级链 + 能源链 + 防御/航天高级建筑。
- 机制：时代条件清单（人口/科技总数/同代科技/观测等级）自动推进；旧时代建筑产出折减（0.8 / 0.6）；建筑升级工程（扣费→旧-1/新+1）；科技时代门槛；E1–E2 观测以食物支付、E3+ 能源支付；Lv.1 观测等级必须通过建造观星台获得。
- 结果：空闲原始部落先降人口后达到新平衡（不会瞬崩）；自动玩家策略可在约 120 年内从 E1 进入 E2 并持续研究/观测；tests/game 20 项回归全绿（含时代门槛、升级链、资源锁定、观测货币）。
