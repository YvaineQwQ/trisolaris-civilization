# 物理模型说明（三维三体 + 行星测试粒子）

## 1. 单位与常数

| 量 | 单位 |
| --- | --- |
| 距离 | AU |
| 质量（恒星） | 太阳质量 M☉ |
| 质量（行星） | 地球质量 M⊕（仅在守恒量核算时换算为 M☉） |
| 时间 | 年 |
| 引力常数 | G = 4π² AU³·M☉⁻¹·yr⁻² |
| 速度 | AU/yr |

固定物理步长 `PHYSICS_DT = 1/1600` 年；游戏时间以 0.25 年/秒（1×）为基准加速，渲染帧率与物理步长完全解耦。

## 2. 引力模型

三颗恒星为完整相互 N-body：

```
a_i = G Σ_{j≠i} m_j (r_j - r_i) / (|r_j - r_i|² + ε²)^{3/2}
```

母星为**测试粒子**：受三颗恒星引力作用，但不回推恒星。由于 M⊕/M☉ ≈ 3×10⁻⁶，该近似误差在游戏尺度上可忽略；行星自身的轨道仍由真实三体引力场决定。

## 3. 积分器

- 速度 Verlet / leapfrog，先 Kick(半步) → Drift → 重新计算加速度 → Kick(半步)。
- 行星与恒星使用同一 KDK 流程；行星加速度在恒星位置更新后重算。
- **自适应子步**：若一步内相对位移与当前间距之比过大（近距交会），在同一个固定步长预算内把该步细分为最多 48 个子步，保证近距离交会不破坏稳定性，同时不改变游戏时钟。
- 软化长度 ε = 0.008 AU：Plummer 软化，将未解析的极近交会/潜在并合替换为平滑势；这是明确记录的物理近似，不是隐藏的误差掩盖。恒星重叠时记录 `softened` 碰撞事件（不模拟质量转移/并合后演化）。
- 溢出保护：任何非有限状态立即标记 `overflow`，行星被判定毁坏，游戏转入相应结局。

## 4. 守恒量诊断

实时跟踪恒星系统的总能量、总动量、总角动量（三颗恒星；行星为测试粒子，其动量注入不属于守恒量），并计算相对能量漂移 `energyDrift`。测试证明：

- 总动量守恒至机器精度（漂移 < 10⁻⁹）；
- 120 年层级三体能量相对漂移 < 1%；
- 300 年三维长跑无 NaN、无溢出。

## 5. 行星命运

- 距离任一恒星小于 `max(2.2 R_star, ε)` → 母星被摧毁；
- 距系统质心超过 60 AU → 被抛射；
- 由 `hazards.ts` 在真实几何上检测近距离交会、轨道扰动与辐照/温度极值。

## 6. 三维轨道与倾角

- 坐标约定：X 水平 / Y 垂直高度 / Z 深度；2D 主视图投影到 X-Z 平面，Y 作为高度提示。
- 随机生成时，内双星、外层伴星、母星各自拥有随机轨道平面（倾角最高约 78°），**不存在默认共面**。
- 轨道要素（半长轴、偏心率、周期、倾角）由瞬时状态反演（二体近似）；三体系统中不存在严格固定的开普勒轨道，UI 中区分「实际轨迹 / 拟合轨道 / 预测轨迹」。

## 7. 随机星系生成与预筛

1. 按难度生成层级三体候选：内双星（a=0.16–0.55 AU，随机偏心率/倾角）+ 外层伴星（4–9 AU，可偏心、独立倾角）+ 母星（求解辐照 ≈ 1 的轨道半径，独立倾角）。温室强度反解为初始地表温度 6–24°C，避免随机 100°C 世界。
2. 用与游戏引擎同构的快速积分器预演 60–270 年，逐项检查：
   - 行星存活、不被抛射、系统能量为负（束缚）；
   - 平均/最小/最大辐照带、最低行星-恒星距离；
   - 温度变化区间与「舒适区间占比」（按难度阈值）；
   - 轨道半径变化范围与混沌代理指标。
3. 通过粗筛的候选再做细步长复核（dt=0.01，≤70 年），全部通过才采纳；若整批无达标系统，则选用评分最高者并在新游戏界面/日志中标注「未通过完整细化预演」。
4. 分类（稳定 / 混沌 / 极端 / 特殊）由预演指标（轨道半径方差、辐照方差、交会频率、抛射风险）计算，不是随机标签。

## 8. 已知近似（明示）

- 行星为测试粒子，不回推；
- 恒星并合只做软化处理，无并合后恒星演化；
- 行星质量不参与恒星动力学；
- 二维主视图为投影，不显示真实深度（3D 视图提供空间结构）；
- 自适应子步只保证数值稳定，不代表对亚步长物理的精确解析。
