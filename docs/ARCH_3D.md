# 2.5D 混合星系架构（TRISOLARIS）

> 本文件是架构强制规范：物理真实、观测受限、2D 清晰、3D 有空间感。

## 1. 唯一数据源

- `PhysicsState` 是唯一真实状态：三颗恒星 + 母星，全部使用三维笛卡尔坐标 **X（水平）/ Y（垂直高度）/ Z（深度）**，AU–Msun–year 单位制，G = 4π²。
- 引力为完整三体相互 N-body；母星为受三体引力影响的测试粒子（不回推恒星），该简化在 UI 与 README 中标注。
- 固定时间步长 leapfrog（KDK，dt = 1/1600 年），积分与屏幕刷新率解耦。
- 2D 主视图与 3D 辅助视图都只读同一份**观测数据**（ObservationState / PlayerModel / PredictionBundle），严禁各自计算天体运动或私藏第二套天体表。

## 2. 2D 主视图（X-Z 俯视投影）

- 屏幕坐标 = (x, z)，Y（高度）不丢失：由标签高度数值 `h=+1.83 AU`、辉光/色深、极淡的垂直指引线等克制元素表达。
- 轨迹：已观测轨迹实线、预测轨迹虚线、不确定性半透明带；全部来自观测/模型数据。
- 支持缩放、拖动、天体拾取、轨迹/预测/网格/标签/不确定范围开关。

## 3. 3D 辅助视图（Three.js）

- 摄像机：轨道旋转、缩放、平移、重置；预设：俯视 / 侧视 / 自由。
- 元素：恒星（真实颜色/亮度差异但不由外观代替物理参数）、母星、已观测轨迹（线）、预测轨迹（虚线/低透明度）、不确定性球/云、轨道平面半透明盘（由真实运动状态拟合，不得统一画成水平圆环）、三维距离标注、选中天体方向矢量。
- 观测限制同样生效：未观测天体不显示真实数据，不确定性以球体半径表达；无高度观测能力时提示"高度数据未解锁"。
- 切换 2D/3D 不重置模拟时间、不改变选中天体、不重新生成星系。

## 4. 观测知识边界

- 观测等级决定能力（位置/距离/速度/质量/加速度/轨道/倾角/高度），低等级看不到高级数据。
- 预测只基于玩家模型 + 蒙特卡洛集成，随时间不确定性增长，最高等级也不能无限期准确。
- 3D 视图角度旋转不会泄露任何未观测信息（它只读观测数据）。

## 5. 验收矩阵（真实运行）

| 验收项 | 方法 |
| --- | --- |
| 2D/3D 同源 | 单元测试：同一 GameState 生成的 scene() 与 scene3d() 的天体 3D 坐标完全一致 |
| 旋转不漏数据 | 3D 渲染器只消费 RenderScene3D，无 physics 导入（静态检查 + 代码评审） |
| 切换不重置 | 集成测试：切换前后 timeYears / 选中 / 观测数据不变 |
| 种子复现 | generation 测试：同 seed 指纹一致 |
| 3D 倾角影响投影 | 测试：高度不同的天体在 2D 投影中 (x,z) 不同、高度提示值不同 |
| 物理真实 | 能量/动量守恒测试；无预设动画（renderer 只读数据） |
| 观测误差传播 | observation 测试：估计误差、预测不确定性随等级/时间变化 |

## 6. 模块映射

- `src/physics/` 三维引力与积分
- `src/generation/` 三维随机星系生成 + 物理预筛
- `src/environment/` 三维距离下的辐照与热惯性气候
- `src/observation/` 测量、估计、玩家模型、预测（知识边界）
- `src/render/` 2D 主视图渲染（X-Z 投影 + 高度提示）
- `src/render3d/` 3D 辅助视图（Three.js）
- `src/ui/` 界面与 2D/3D 切换
- `src/game/` 统一游戏循环、视图数据装配（ViewModel / RenderScene / RenderScene3D）
