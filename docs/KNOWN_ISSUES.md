# 已知问题与设计边界（v1.2.0）

## v1.2 更新说明

- 存档版本升级为 v2：建筑/科技 id 与时代系统重构，v1 旧存档不兼容（读取时提示版本不兼容）。
- 观测不确定几何视觉上限：低等级时真实不确定度可达数 AU，为避免 2D/3D 画面被巨大圆球淹没，不确定环/球半径视觉上限 3 AU；面板与标签仍显示真实数值。
- 原始时代经济：E1 人口 500 时食物略有缺口，需要尽快补建原始农田；空操作会先降人口后达到平衡（设计上鼓励建设，不是瞬崩）。
- 3D 视图：软件渲染（无 GPU 的无头环境）首挂约 8–14 秒；真实 GPU 正常。
- 美术：AI 生图 API 在本环境持续不可用，即梦网站无法被自动化调用（浏览器未开调试端口且需登录）；当前资产为原创程序化渲染与 SVG，后续可由用户手动生成同名文件覆盖。

## 科学模型简化（已明示）

1. **行星为测试粒子**：母星受三颗恒星引力，但不回推恒星。误差量级 M⊕/M☉≈3×10⁻⁶，对恒星运动可忽略；但严格意义上不是完整 N-body。
2. **恒星并合未演化**：恒星重叠时采用软化势并记录事件，不模拟并合后的质量转移/新恒星。极端近距交会（<0.01 AU）的物理细节被平滑。
3. **自适应子步**：为数值稳定细分步长，但不对亚步长物理做解析；近距交会精度受软化长度限制。
4. **质量估计为游戏化融合**：观测系统用带弱先验的加权融合估计恒星质量，而非完整光度/动力学反演；这是为了让 3 级天文台"初步估算质量"可玩，已标注为简化。
5. **预测早停**：集合发散后预测样本以 σ 指数外推（位置冻结），不是继续硬积分；这是有意的性能/诚实性设计，UI 会显示「已发散」。
6. **观测轨迹混合实测点与模型点**：当前观测轨迹数组未分虚/实；UI 以实线统一绘制。
7. **行星速度未单独建模不确定性**：行星 `PlanetEstimate` 无 sigmaVel 字段，预测对行星速度扰动为启发式。
8. **轨道要素为瞬时二体反演**：三体系统没有固定开普勒轨道；面板显示的是瞬时拟合值。

## 功能边界

9. **殖民地系统较简化**：殖民地为单一「火种站」，成长由人口阈值驱动；无独立殖民地经营界面。
10. **社会政策**：规格中提到「社会政策」，当前以稳定度因子与建筑/科技效果体现，尚无独立政策卡系统。
11. **音频**：设置中音量滑杆为明确标注的占位（无音频资源），不产生声音。
12. **AI 生图不可用**：本次环境图像生成 API 全部失败，美术资产改为程序化渲染 + 手绘 SVG；风格统一但精细度低于 AI 插图，后续可按 `docs/ART.md` 的 prompt 覆盖同名文件。
13. **3D 视图性能**：Three.js 走软件渲染（无 GPU）时帧率较低；真实 GPU 环境正常。3D 视图按需动态加载（550KB / gzip 142KB）。
14. **浏览器兼容**：以 Chromium（Chrome/Edge）为主要目标；Firefox/Safari 未做完整验证（IndexedDB/WebGL 应为通用能力）。
15. **无移动端适配**：规格要求 PC 16:9；小屏（<1280×720）布局可能拥挤。

## 已修复但值得记录的问题

- 行星质量单位错误（曾把地球质量当太阳质量）→ 守恒量诊断与测试暴露，已修正；
- 积分器在近距交会时失稳 → 自适应子步；
- 随机温室导致 100°C 开局 → 反解温室使初始温度 6–24°C + 温度带预筛；
- 灾害轨道扰动阈值过低导致永久灾害 → 阈值 0.55 与缩短持续时间；
- 开局农场/水厂/电站不足导致早期必然饥荒 → 起始建筑调整为 3 农场 / 3 居住 / 2 水厂 / 2 电站；
- UI 速度按钮与模拟时钟未驱动问题 → Game 由渲染轮询驱动真实时钟，物理步长不变；
- 3D 渲染器临时文件与 Vite EBUSY 监视崩溃 → 清理临时目录 + polling watcher。
